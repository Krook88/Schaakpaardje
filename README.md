# 🐴 Schaakpaardje

Nederlandse leer-app waarin kinderen van 3 tot 10 jaar leren schaken, met Pip het
schaakpaardje als sprekende mascotte, een modulepad in spelvorm en oefenpartijen op
tien niveaus.

> **Status:** planfase. Er is nog geen code — begin bij **[PLAN.md](PLAN.md)**.

## Documentatie
- [PLAN.md](PLAN.md) — het volledige ontwikkelplan (start hier)
- [docs/](docs/) — onderzoek, didactiek, curriculum, techstack, architectuur, UX,
  privacy, roadmap en risico's

## Kern in vijf regels
- **Didactiek:** Nederlandse stappen-volgorde — makkelijk stuk eerst, mat bewust laat.
- **Vorm:** 15 werelden, elke les *kijken → meedoen → zelf doen → sterrentoets*.
- **Geluid:** alles gesproken; vooraf gerenderde audio, werkt offline.
- **Stack:** Next.js + TypeScript PWA, chess.js, react-chessboard, stockfish.wasm, Rive.
- **Privacy:** geen account, geen advertenties, geen chat, alles lokaal.
